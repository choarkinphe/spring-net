# 统一站点库与组合

日期：2026-10-27。基于 v0.5.0 开发；后按用户要求升级为 v0.6.0，重新构建 macOS arm64 包并退出旧版、打开新版。v0.6.0 已提交为 a14af64；此后维护页分栏调整尚未提交或重新打包。

## 界面与语义

顶部仅两个入口：基础检测 / 常用站点。检测页保留六工具，站点快捷选择默认折叠。管理页左右分栏：左侧为全部站点、内置分组和我的分组（含成员数），右侧为所选分组说明、维护操作、名称/地址搜索和站点列表。窄屏改为上分组、下列表。编辑仍使用弹窗，不恢复历史工作台。切组只筛选、不保存或检测；当前分组删除后回到全部站点，检测页快捷分组选择独立。

- 七组内置预设、55 个站点来自现有 presets：首页参考、只读，附原来源和核实日期。没有将 GDS 的未知配置或通配规则转换成检测站点。
- 站点有唯一 ID、名称、地址和可选默认端口；组合引用站点 ID。一次修改同步到所有组合。允许未分组站点、空组合。
- 复制组合沿用原站点引用；复制站点生成独立可编辑记录。
- 删除站点前显示受影响组合，确认后删除记录及其自定义组合引用。删除组合不删站点。
- 选择站点只填草稿，不自动检测。非 HTTP 工具取 URL 主机，HTTP 保留完整路径；裸主机不能直接填作 HTTP 网址。TCP/TLS 默认端口优先使用站点配置，其次采用完整 URL 的端口/scheme；不猜裸域名端口。
- 地址不接受凭据、查询、片段、脚本协议、网段、通配、多目标和末尾点号域名。默认端口与 URL 显式端口冲突时拒绝；HTTP 不隐式使用独立默认端口。

## 存储与兼容

数据根下 `site-catalog.json` 仅保存自定义站点/组合，version=1，revision 单调增加。固定路径、严格 DTO、原子写入；内置标记与来源只能由后端生成。最多 1000 个自定义站点、50 组、10000 个引用、最终 JSON 1 MiB。

新文件不存在时，读取旧自定义 SiteList 在内存迁移；列表/目标 ID 联合命名空间，只有同名同规范化地址才合并，不同名称保留。不在读取时写文件；首次明确保存目录才持久化。旧 lists.json 和旧 API 保留，不双向同步。

保存使用服务 mutation 门闩和 revision CAS。文件损坏、超限、符号链接或外部改动失败明确，不覆盖。运行期外部改文件需要备份并重启，重新读取只返回服务内存。字节检查不是跨进程锁，禁止多个进程共享数据根。

HTTP GET/PUT `/api/site-catalog` 和原生 `site_catalog` / `save_site_catalog` 使用同一 AppService。HTTP 保留 Host、Origin、会话令牌、JSON 和请求体限制。保存不解析 DNS、不连接目标、不授予检测或负载权限。检测运行/收尾及前端状态不确定期间禁止修改与草稿填充。

写结果不确定时只重新读取核对，不重发；核对失败锁定修改直到明确重读成功。多窗口 revision 冲突后重载目录，旧编辑弹窗不可继续覆盖，需取消并重新编辑。

## 验证结果

- Rust 全套：170 项通过；含 12 项 catalog 单元测试、HTTP 同源/token/严格字段/共享引用/CAS/惰性读取回归。
- JavaScript + 版本测试：73 项通过，覆盖共享 DTO、删除引用、未知写核对、冲突锁定、工具特定草稿填充且零自动启动。
- cargo fmt、Clippy（lib/tests，warnings=deny）、Tauri locked/offline 编译检查、git diff --check 通过。
- 使用现有统一启动脚本与隔离数据目录 `target/network-tools-verification/data`，健康检查就绪。
- 浏览器实际完成：创建站点、建立两个组合并引用、一次编辑同步、搜索/筛选、删除影响含两个组合、取消删除、用于检测只填草稿；复制内置六成员组合后删除，站点数不变；删除共享站点后保留空组合；折叠快捷选择并填入域名。
- 375px 视口页面宽度同为 375，无横向溢出；恢复桌面视口。预设只有“用于检测/复制”操作，管理页无 console 错误。重启服务时产生过两条页面连接拒绝记录，后续导航 HTTP 200、目录正常，非目录请求失败。
- 本批验证没有主动启动公共站点检测；站点保存使用 example.invalid，保存/选择均不发起探测。Preview 后续读取到已有检测状态（本轮操作未启动该检测），不将其结果当作站点管理功能验收证据。

## 后续维护页分栏调整

v0.6.0 提交后按用户要求将维护页改为左侧分组导航、右侧站点列表，不改后端与数据格式。前端与版本测试 77 项通过，含切组筛选/搜索、焦点保留、删除当前组回退、刷新选中保留、快捷选择隔离。Preview 桌面视口已确认 Grid 为 210px + 自适应列表栏、无横向溢出、无 console 错误。

随后按用户反馈：切换分组清空搜索词；移除“复制组合”和“重新读取”按钮；新增组合/站点统一用带 title 与 aria-label 的 `+`。再次点击顶部“常用站点”会读取目录，保留保存结果未知时的核对恢复路径，不自动重发写入。此轮前端与版本测试 79 项通过；Preview 重启受工具暂时不可用影响，最新精简控件尚未完成浏览器复验。
