# 分层诊断：使用方式与结果边界

此页描述本批实现的接口与语义；实际执行的验收另记，不将实现说明当作通过证明。

## 操作

从“分层诊断”页输入一个精确主机、IP或HTTP(S)地址和单个端口，选择是否进行TLS握手。局域网目标需明确允许；默认仅公网。预设只能填入确切地址且有已知端口的配置，通配规则和未知地址不能运行。填草稿、打开资料或刷新页面均不开始诊断。

诊断顺序为DNS → 路由 → TCP → TLS。无业务HTTP、认证、订座或出票请求。URL中的路径不被请求；诊断针对主机、端口和可选TLS。HTTPS可建议TLS，但不能仅因端口443就断定协议。

开始前显示预算；诊断与原有HTTP/TCP实验互斥。停止后等待收尾，不能将“停止请求已发送”解释为全部资源已释放。仅保留本进程内最近一次结果，需长期留存应导出JSON；重启不恢复诊断历史。

## 四层结果

### DNS

使用操作系统名称解析视图，可能包含hosts、缓存及VPN/分流DNS的影响。记录解析耗时和返回地址，全部地址校验后固定一个供本轮使用；其他地址列为未测，不自动重试/回退。IP字面量无需DNS。

不提供该API无法观察的DNS服务器、TTL、CNAME链、DNSSEC或权威RCODE；系统解析耗时不等于纯DNS网络RTT。

系统解析无法可靠强制取消。等待超时或停止后不再执行后续阶段，但若底层解析尚未返回，保持draining并阻止新任务，避免堆积解析线程。退出最多额外等待2秒并记录未完成事实；随进程退出不等于已取消解析。

### 路由

macOS使用系统traceroute/traceroute6，UDP、最多20跳、每跳1次；Windows使用系统tracert，ICMP、最多20跳、每跳固定3次。关闭反向解析，目标为已固定数值IP。最多30秒，stdout/stderr合计最多64KiB，达到上限或取消后结束并回收本次子进程。

权限不足、工具缺失、未适配平台或部分跳点无响应均明确展示；不自动提权。路由失败不阻止后续TCP/TLS，用户取消或整体截止除外。自检回环目标不执行路由追踪。

`*`仅指未收到预期响应，不能直接定位网络故障；最后响应跳点不是已确认的故障位置。UDP/ICMP探测也不保证与业务TCP走相同路径。保留有界原始输出，解析未知格式时不猜测已到达。

### TCP

向固定IP/端口仅建连一次，无隐藏备用地址或重试。记录成功、拒绝、超时或其他错误与耗时。成功仅表示本机观察到连接建立，不代表登录、查询或出票成功。

### TLS

在刚成功的同一条TCP连接上握手，不再建第二条连接。原域名用于SNI及主机名校验；IP目标使用IP证书身份校验。TLS失败不覆盖TCP成功。

生产信任根为随应用打包的Mozilla根（webpki-roots），不是macOS Keychain或Windows系统证书库。企业私有CA即使已装入系统也可能不被信任。工具不关闭证书校验、不自动获取AIA/OCSP、不发送业务请求。协商版本/cipher仅在实际观察到时展示，不虚构证书签发人或有效期。

## 安全与预算

单目标、单端口、无地址范围/扫描/任意命令参数。公网与显式允许的RFC1918/ULA内网适用不同准入，混合DNS答案全部校验。拒绝链路本地/云元数据、组播/广播/未指定及其他特殊地址，并保守禁止浏览器控制端口。普通用户不能选择任意loopback；设置显式启用的本工具自检服务仅针对实际拥有的端口例外，不代表外网。

固定预算：DNS5秒、路由30秒、TCP5秒、TLS5秒、正常执行整体60秒。OS解析收尾及进程回收不因UI超时被隐藏。全局启动间隔5秒、同主机间隔30秒；不能用重复点击、自动重试或并发执行扩大为压力测试。

## JSON与接口

共享业务接口为：
- `POST /api/diagnostics`：严格配置与request UUID，显式开始。
- `GET /api/diagnostics/state`：只读最近快照。
- `POST /api/diagnostics/stop`：匹配诊断UUID的幂等停止。
- `GET /api/diagnostics/report?id=...`：匹配最近结果的JSON报告。

HTTP保持本机Host/Origin/令牌保护；桌面使用固定IPC映射。相同request UUID及配置返回原任务，不自动重复执行；UUID与配置冲突拒绝。请求超时结果不确定时先读取状态核对，不自动重发。旧UUID不能导出当前新任务。

报告包含方法、固定目标、计时、原始证据、未执行/未知/错误状态及限制，不含会话令牌或凭证。数据仅说明当前客户端到该目标在该时刻的表现；不自动证明运营商PCDN判定、路由器故障或全网最大连接数。
