# 应用、网站与标签目录 v3

2026-10-28。基于当前0.9.0工作区增量实现；本轮未升级应用版本、提交或打包。

## 使用方式

- 顶部“站点管理”维护网站首页、子页面和HTTP(S)接口；“应用管理”维护微信、QQ、钉钉、Sabre、Travelport等软件/服务的功能连接。
- 两页共用标签与分组，每资源可以有多个标签。分组关联多个标签，按任一匹配（OR）纳入并去重；空标签组匹配零项。跨类分组在两页分别显示对应资源。
- 标签可新增、改名和删除；删除前显示资源及分组影响，最后一个标签移除后分组为空。预设标签只读，允许给资源附预设标签；基础预设分配不可移除。
- 预设身份、来源和官方配置保持只读，可以直接添加个人标签、连接与规则。“预设资料”和“我的配置”分区展示，个人配置不视为官方核实。
- 网站具体连接必须为明确HTTP(S)/TCP及完整URL，允许跨域登录、CDN和子接口；应用可以使用已有多协议。保存、筛选、打标签和选择草稿均不自动检测。
- 继续使用加号、搜索点选、radio/checkbox，不恢复下拉、复制分组或永久重读按钮。再次进入管理页读取最新目录。

## 数据与兼容

固定site-catalog.json升为version3。严格保存包含schema_version=3、expected_revision和sites/applications/groups/tags/tag_assignments/resource_supplements。Snapshot有效标签和组application_ids由服务器派生，不能回传伪造。保留CAS、源文件字节核对、原子写入、符号链接/损坏/超限失败保护。

v1/v2及旧列表只读内存迁移，资源/连接/分组ID与revision不变，首次明确保存才写v3。每旧组派生专属标签、只标旧成员，保持原成员集合；同名/大小写/预设同名标签使用有界后缀区分。原category作为兼容信息保留，不自动生成额外分类标签。自定义旧web仅在全部连接明确HTTP(S)时迁为网站，其他保留应用并提示需确认类型，不丢连接。旧版本无法读取v3，回退应用需配合旧数据备份。

预设个人补充使用独立overlay，只能引用自定义连接和个人规则，不覆盖官方身份或来源。网站约束也校验共享连接的全部引用者。

限制：1000自定义资源、1000连接、50自定义分组、256用户标签；每资源/组最多100标签；每资源有效连接和规则各100（保持合法v2兼容）；引用总预算250000，最终持久化仍不超过1MiB，超限明确失败不截断。

## 测试任务

组成员为服务端标签OR投影。新请求带可选resource_selections明确(group_id,resource_id)，避免共享连接把未选资源当作来源；旧请求省略字段时保持原行为和序列化intent。

已保存任务保持固定范围：新标签匹配成员不自动加入，标签改名不改变执行身份。原组删除/成员解除、端点或资源删除、地址/协议改变、资源解绑仍要求更新任务。旧任务与历史报告不重写。标签不授予网络或负载权限；许可、代理、预算、取消/归档保护保持。
