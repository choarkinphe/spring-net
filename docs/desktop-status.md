## 本次实现

- GUI 授权目标新增、编辑、删除、完整配置修复、固定文件重新加载。完整规范化预览后单独确认；草稿限时、绑定修订与文件内容，重复确认不重复写入。外部改动使旧预览失效；加载失败保留旧列表供查看但阻止授权运行。
- 过期许可可查看/编辑，不能用于运行。开始时校验 DNS/CIDR、额度及覆盖执行时长，执行中也约束到期；不关闭 TLS、不跟随跳转/代理/重试。
- 自检改为设置中显式开启、仅当前会话有效，随机端口不保存到方案。
- 公共目标逐项勾选，使用列表/目标限定引用避免重复 ID 歧义；GUI 零选择不运行。整数 RPS、30 秒超时、公共 120 秒时长与后台一致。
- 测试方案保存/载入/删除；载入仅填草稿。工作区页、排序、面板/列宽持久化；结果筛选、排序、行详情及曲线/采样表标签。
- 终态归档不依赖前端轮询；开始标记恢复为中断，历史默认最多 100 轮 / 100 MiB、单文件 8 MiB。按 UUID 查看/导出旧轮结果；清空需确认。完成网络清理和归档后才暴露终态。
- HTTP 与原生 IPC 共用业务服务；保持写入不确定时不自动重试。
- 429/503 在响应头到达时发布同域退避，公共 Retry-After 在读 body/取消前持久化，避免收尾遗漏。
