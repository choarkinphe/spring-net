# 系统设置：应用内统一代理

日期：2026-10-28。源码功能；本轮没有提交、升级版本、打包或替换桌面应用。

## 使用

系统设置内用 `+` 新增代理，填写名称、类型、主机、端口。支持无认证 HTTP CONNECT 和 SOCKS5；可以保存30组，单选其中一组启用，或选“关闭代理 / 直连”。保存/启用决定后续路径，不建立后台隧道、不解析目标，也不修改操作系统代理。启用后会自动进行低频代理端点健康检查。删除当前项会先明确确认切回直连。

- TCP、TLS、HTTP、新目录批量及既有连接测试由共享服务自动采用当前配置。各任务启动时冻结代理配置与修订，历史结果不随新配置改变。
- Ping、Traceroute、DNS 保持用户指定目标的本机检查，明确标注不经代理；没有把目标替换成代理端点。连接测试的目标域名同样本地解析，HTTP/SOCKS5仅发送已校验的数字目标，不提供远端DNS。
- HTTP保持HEAD/无跳转/无重试/不读取正文，TLS继续使用原主机SNI和正常证书校验（随包Mozilla根）。TCP代理结果是隧道建立，不冒充目标TCP RTT。
- 失败不回退直连，不切换其它配置或其它解析IP。请求级旧代理仅作一致性校验，不能覆盖全局设置。已有幂等请求返回原路径，不以当前设置重新执行。
- 检测运行/停止/系统DNS收尾期间禁止改配置；前端状态未知同样锁定。保存未知结果只读核对，不重发；重新进入系统设置可恢复读取。

## 底部代理端点状态

所有页面共用固定 footer，显示当前代理、检查状态、上次完成时间和耗时。后端启动后只对当前启用项立即首检，此后每30秒一轮，整轮5秒预算、不重叠；关闭代理停止探测。

HTTP仅建立代理TCP然后关闭、发送零应用字节；SOCKS5仅发送3字节NOAUTH greeting并校验响应，不发送CONNECT或任何目标地址。可达只表示代理端点可连或接受NOAUTH，不等于目标转发可用。手动检测优先，后台健康检查暂停；独立DNS配额最多1个真实OS解析线程，不进入业务DNS准入，超时/取消后线程仍占槽直到实际结束。设置切换取消旧检查并丢弃旧结果，GET `/api/proxy-health` 和IPC `proxy_health` 仅读缓存，不产生探测。前端每秒读取缓存、失败显示未知而不是直连。

新增健康Rust定向8项及footer/设置前端11项通过，Tauri locked check通过。健康测试涵盖HTTP零字节、SOCKS仅greeting/错误响应、取消关闭、纯读取、切换首检及无重叠。当前Preview工具间歇不可用，固定footer视觉验收尚未完成，不将其它页面历史截图当证据。

## 存储与授权

独立 `data/proxy-settings.json`，version=1、revision CAS，严格DTO，最大64KiB、30组；固定路径、普通文件、原子写入，损坏或外部改动明确报错，不静默变为直连。数据根不能由多个进程共享。

新文件不存在时将旧 `settings.json` 合法 http_proxy 只在内存迁移为未启用配置，首次明确保存才写入。新旧设置不双向同步。旧外观设置全量保存不会覆盖新代理库。

代理配置不是负载授权。授权HTTP/TCP仍需目标许可，并明确允许精确代理URL/协议、代理全部解析答案所在CIDR及授权依据。缺失路径在启动前拒绝，不自动添加授权。批量授权弹窗有可选代理路径字段，需完整预览并确认。

HTTP GET/PUT `/api/proxy-settings`、原生 `proxy_settings/save_proxy_settings` 共用AppService；保留Host/Origin/token/JSON/body限制，无任意路径、shell或凭据字段。
