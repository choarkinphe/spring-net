日期：2026-10-27。核心、桌面、npm/Tauri及锁文件已同步0.4.0。

## 本次前端接入
- 系统监控首页：全宽分组卡片、添加弹窗、每次手动开始、暂停/停止；状态区显示当前代次实际代理路径。
- 设置保存无认证HTTP代理地址，不自动选择路径、不修改系统代理；监控、批量、单站诊断、时长/负载分别选择直连或代理。
- 代理方案可正确载入并保存proxy；后台不支持/地址非法则保留原草稿并报错，不静默降级直连。
- 授权普通编辑和完整JSON编辑保留proxy_routes，并通过完整预览/确认保存。
- HTTP代理显示每请求独立HTTP/1.1隧道，不宣称连接池复用；TCP代理显示已建立代理隧道，不宣称独立观察到目标TCP。
- 诊断摘要区分代理TCP/CONNECT/目标TLS，路由注明追踪代理，代理后的路径未知。
- 批次JSON导出支持浏览器和Tauri原生保存面板。
- 修复监控因407停止后，心跳报错导致状态一直无法刷新的问题：心跳失败仍读取快照确认终态。

## 实际Preview验收
隔离实例9901，配置/授权仅写`target/release-verification/`；模拟代理监听127.0.0.1:9902(固定成功响应)、9903(407)。**该fixture不解析或连接任何目的目标，只记录CONNECT和HTTP请求后返回固定响应。** 未测试真实航司/OTA/GDS或公网负载。

- 设置保存9902后，测试仍默认直连；各路径输入预填已保存代理但须显式选择。
- 经GUI编辑隔离授权目标并完整预览：proxy_routes的地址/CIDR/说明保留。
- 代理TCP负载2隧道/1起发每秒/5秒完成，界面显示“已建立代理隧道”；模拟代理记录2次数字CONNECT。
- 代理HTTP负载1并发/1 RPS/3秒完成，3次HTTP204、零错误，显示独立隧道不复用；仅本机固定响应，不能代表真实网络吞吐。
- 监控通过9902取得CONNECT成功，TCP显示未知（目标未独立观测）；停止完成。
- 9903返回407后监控停止；修复后页面成功刷新失败记录与停止状态，不回退直连。
- 单站诊断通过9902完成，摘要为CONNECT成功/TLS未测试，明确代理实际远端IP和后半程路由不能独立确认。
- URL/地址策略实际拒绝文档保留IP作为代理目标，未放宽安全边界；验收改用只在CONNECT报文中出现的私网地址且代理不转发。

## 限制
- 无认证HTTP CONNECT代理；407明确失败。不是SOCKS/PAC/系统代理，也不支持账号密码。
- 目标DNS仍在本机解析；代理必须支持数字IP及所选端口的CONNECT。TLS使用Mozilla随包根，不是系统/企业CA。
- Windows未原生验收；本次macOS只做重新打包与签名/压缩包校验，原生保存面板完整实际落盘矩阵仍未覆盖。
- 监控每次打开仍须手动开始。新包不包含本机验收配置、示例授权或模拟服务，用户原有数据不被替换。
