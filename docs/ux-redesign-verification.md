# 单系统排障首页验收

日期：2026-10-27。版本仍为0.3.0；本次未自动改版本或重打包。

## 改动

- 默认首页为“单系统排障”；无hash时不再由旧持久化设置打开多功能控制台。显式`#console`、`#lists`等旧hash仍可访问。
- 侧栏以“单系统排障”为主入口，其余分为巡检/承载测试、站点与连接资料、承载授权等可识别功能。
- 单系统流程依次为目标选择、连接方式核对、查看排查结果；支持搜索网站入口和业务连接参考、手动填写。
- 选择只填草稿；GDS地址不明确时不能选为可执行目标。TLS仍需明确选择，LAN仍默认关闭。
- 结果先给“连接已成功/TLS未测试”等观测摘要和下一步，再折叠展示分层证据，未改变底层判定和权限。
- 本机回环自检结果专门说明“不经过办公网络出口、不代表业务系统可用”。

## 验证

- 后端76项测试通过。
- 版本管理 + 前端全部node测试通过，app.js语法检查通过。
- 9895隔离Preview健康就绪。空hash首次进入单系统排障；未向任何目标发起请求。
- 页面切换到旧“巡检与承载测试”成功。
- 搜索“国航”能找到“中国国际航空 · 官网入口”；选择后只填入`https://www.airchina.com.cn/`草稿，TLS保持未选择、LAN保持关闭，没有非本机资源请求。
