# Ping / Traceroute 最小版本

日期：2026-10-27。仅实现两个指定站点的基础工具，不继续堆叠监控、代理、批量或承载功能。

## 界面

主页面仅加载network-tools.js/css：一个站点输入、Ping/Traceroute选择、开始/停止、真实输出和简明结果。旧工作台HTML保留为web/legacy-workbench.html，旧代码和用户数据未删除，也不由新首页初始化。

- Ping默认4次、间隔1秒、10秒进程上限。
- Traceroute默认20跳、macOS每跳1次、30秒总上限。
- 只接受一个域名/IP或HTTP(S)网址；网址只取主机，不访问页面；系统解析全部检查后固定一个地址，其他地址不自动重试。
- 子进程固定系统路径、无shell/任意参数/提权，有界64KiB输出，取消/超时/掉落后由所有者kill+wait回收。
- 超时不直接代表网站故障；路径星号不定位故障节点。系统工具原始输出保持原文，界面提示与汇总为中文。
