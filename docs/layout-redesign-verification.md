## 已改动
- 监控首页去掉大号教学横幅和常驻添加表单，改为紧凑标题、搜索/监控工具栏及全宽分组卡片。

- 控制台配置区在前/左、结果区在后/右，移除 `display:contents` 与显式grid行号造成的混排；单站排障标题缩为紧凑页面标题。
