使用说明
01 / 测试边界
测试模式
轻量探测 / PROBE
逐个勾选列表内的目标；未勾选任何目标时禁止运行。公共探测并发、速率和冷却期由后台限额约束；保守地按末两级域名共享保护，并非精确的同注册域识别。例如 *.co.uk 会合并到 co.uk，限制更严格。重复目标的合并以后台为准。
HTTP 请求
仅能选择后台明确允许 HTTP 的自有、已授权或本机目标。支持渐增流量及强制每次新建连接。勾选列表或导入 JSON 都不会授予测试权限。
TCP 连接
仅能选择后台明确允许 TCP 的目标。配置的速率上限指建连尝试速率，观测速率指连接生命周期结束速率；“已连接”是真实在本机持有的 socket 数，不是远端全局连接数。TCP 不存在 HTTP 成功率。
02 / 读数定义
读数定义
尝试 / 已完成 / 错误 / 取消
分别使用后台 attempted、completed、errors、cancelled。completed 是已结束的 HTTP 请求或建连尝试，不等于成功。错误与取消独立展示，不从完成数推导。
HTTP 2xx/3xx 比例
HTTP 2xx/3xx 比例 = good_status ÷ responses；未收到响应时显示“—”。good_status 是 HTTP 2xx/3xx 响应计数，不代表业务层成功，也不代表所有尝试的成功比例。TCP 模式不适用。
速率 / 延迟
速率、P50 和 P95 直接来自后台，不根据页面刷新频率计算。TCP 模式的 rps 是连接生命周期结束速率，不是新建连接速率；“已连接”仍表示本机当前持有的真实 socket。延迟直方图固定按 1 ms 分桶；TCP 延迟表示建连尝试延迟。两个趋势图各用一个独立纵轴；无采样或无有效延迟时不补零、不生成曲线。
数据与导出
JSON 下载当前 Run，CSV 下载后台汇总。列表 JSON 仅包含自定义列表，可在前端导出与导入；不携带令牌、内置标记或授权上限。
03 / 操作流程
配置 → 检查摘要 → 明确开始 → 观察 → 停止或完成
页面加载不会运行测试。负载测试必须逐次确认目标权限；浏览器写操作附带后台启动令牌；桌面版通过受限的原生 IPC 命令操作，不使用 HTTP 令牌。测试运行期间锁定配置，可随时请求停止；“停止中”表示后台仍在收尾，并非已结束。
浏览器通过 SSE 获取实时快照；桌面版每秒查询状态，前次查询结束后才安排下次查询。连接中断时会保留最近读数并标注非实时，同时重新查询状态；连接恢复后自动同步。重新连接不会重复创建测试。公共冷却期及全部权限最终由 Rust 后台强制执行，前端限制不能替代后台校验。
不要对第三方未授权目标进行负载测试。即使目标可访问，也不代表你拥有测试许可。
